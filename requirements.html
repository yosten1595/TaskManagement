この書類で使う言葉の解説

パソコン操作に慣れていない方のために、この書類で繰り返し出てくる言葉を事前に説明します。

📋ボード
プロジェクトや用途ごとに作る「作業スペース」。例えば「ECサイト開発」「日常タスク」のように使い分ける。アプリを開いたホーム画面に一覧で並ぶ。
🗂️カンバンボード
付箋をホワイトボードに貼り並べて進捗を管理する手法をデジタル化したもの。タスクを「未着手」「進行中」「完了」などの列に並べて、状況を一目で確認できる画面。
📑リスト（列）
カンバンボードの中にある縦の区切り。「未着手」「進行中」「完了」などの状態を表す。自由に追加したり名前を変えたりできる。
🃏カード
リストの中に並ぶ一つひとつのタスク（やること）。付箋1枚に相当する。タイトル・期限・優先度・チェックリストなどの情報を持つことができる。
📝詳細モーダル
カードをクリックすると画面の上に重なって表示されるウィンドウ。カードの詳しい情報（説明・期限・チェックリストなど）をここで編集する。「モーダル」＝「画面に重ねて表示する窓」のこと。
🖱️ドラッグ＆ドロップ
マウスのボタンを押したままカードを別の列へ移動させる操作。例えば作業が終わったカードを「進行中」から「完了」列へ移すときに使う。スマートフォンでは指でなぞる操作にあたる。
00

現状の課題と、このアプリが解決すること

多くの企業では、タスク管理を付箋・ホワイトボード・PC のメモ帳で行っています。これらには以下のような共通の課題があります。

現状（付箋・メモ帳での管理）
  • ✗期限が近づいても誰も気づかず、作業が遅延する
  • ✗どのタスクが急ぎなのか、優先度が一目でわからない
  • ✗タスクの中の細かい作業（サブタスク）が管理できない
  • ✗プロジェクトが増えると情報が混在して見つけにくい
  • ✗現在の進捗状況をチーム全体で共有しにくい
TaskBoard を使うと
  • ✓期限が近づくと自動で色が変わり、見落としゼロへ
  • ✓優先度・ラベルでタスクの重要度が一目でわかる
  • ✓カード内のチェックリストでサブタスクと進捗を管理
  • ✓プロジェクトごとにボードを分けて整理できる
  • ✓カンバンボードで進行状況をチームで即座に共有
01

プロジェクト概要

アプリ名
TaskBoard（タスクボード）
目的
個人・小規模チームのタスクを視覚的に管理し、期限・優先度・進捗を一目で把握できるカンバン型ツールを提供する。
主要ユーザー
個人の作業管理から2〜10名規模のチームまで対応する汎用型。
提供形態
シングルページ Web アプリ（ブラウザのみで動作。サーバー不要。）
データ保存
ブラウザの localStorage に保存。オフラインでも完全動作する。
02

ユースケース一覧

「誰が（アクター）」「何をしたいか」「どう操作するか（主フロー）」をまとめる。全ケースのアクターは ユーザー（個人・小規模チームメンバー）。
UC番号 ユースケース名 事前条件 主フロー（概要） 後条件（結果）
UC-01 ボードを作成する ホーム画面を開いている ①「＋ボード追加」をクリック → ②名前を入力 → ③確定ボタンを押す 新しいボードがホーム画面に追加される
UC-02 ボードを削除・名前変更する ホーム画面にボードが1件以上ある ①ボードカードのメニューを開く → ②「名前変更」または「削除」を選ぶ → ③確定 ボード名が更新される、または一覧から削除される
UC-03 リストを追加・削除する カンバンボード画面を開いている ①「＋リスト追加」をクリック → ②名前を入力 → ③確定。削除はリストのメニューから「削除」を選ぶ 列が追加または削除される
UC-04 カードを作成する カンバンボード画面にリストが1件以上ある ①リスト下部の「＋カード追加」をクリック → ②タイトルを入力 → ③確定 新しいカードがリストに追加される
UC-05 カードをドラッグ&ドロップで移動する カンバンボード上にカードが1枚以上ある ①カードをドラッグして移動先リストへドロップする カードが目的のリストの指定位置に移動する
UC-06 カードの詳細を編集する カンバンボード上にカードが1枚以上ある ①カードをクリック → ②詳細モーダルで説明・期限・優先度・ラベルを編集 → ③モーダルを閉じる 編集内容がカードに反映・保存される
UC-07 チェックリストで進捗を管理する カード詳細モーダルを開いている ①「＋アイテム追加」でサブタスクを追加 → ②完了したアイテムにチェックを入れる 進捗バーが更新され、カード上に「○/○完了」と表示される
UC-08 期限警告を確認する 期限付きカードがボードにある ①ボードを開く → ②カードの期限状態（赤・黄・緑）を視認する 期限切れ・間近のカードが色で強調表示されている
UC-09 キーワード検索・フィルタを使う カンバンボード画面を開いている ①検索バーにキーワードを入力、またはフィルタ条件を選択 → ②一致するカードが強調表示される 条件に合うカードのみが目立って表示される
UC-10 テンプレートからカードを作成する テンプレートが1件以上保存されている ①「テンプレートから追加」を選ぶ → ②一覧からテンプレートを選択 → ③作成されたカードの期限などを必要に応じ編集 テンプレートの内容がコピーされた新規カードがリストに追加される
UC-11 データをエクスポートする ボードが1件以上ある ①メニューから「エクスポート」を選ぶ → ②JSON ファイルがダウンロードされる 全ボードデータが JSON ファイルとして保存される

05

非機能要件

⚡パフォーマンス
ドラッグ&ドロップを含む全操作が 100ms 以内に応答。カード100枚以上でも動作が重くならない。
📱レスポンシブ対応
スマートフォン（幅 375px〜）からデスクトップ（1440px）まで、崩れなく表示・操作できる。
🔌オフライン対応
ネットワーク接続なしで全機能が動作する。データは localStorage に保存され、再読み込み後も維持される。
♿アクセシビリティ
キーボードのみでの操作をサポート。フォームにラベルを付与し、カラーコントラストは WCAG AA 基準以上。
🖥️ブラウザ対応
Chrome / Firefox / Edge / Safari の最新2バージョンで動作確認する。
🔒セキュリティ
外部サービスへのデータ送信なし。XSS 対策として innerHTML を使わず textContent を使用する。

07

データ機能（CRUD仕様）

アプリが扱う各データに対して実行できる操作（作成・読み取り・更新・削除）と、データの保存構造をまとめる。データは localStorage の taskboard_data キーに JSON 形式で保存される。
7.1 CRUD操作一覧
機能ID対象データ操作トリガー（きっかけ）説明
DF-01BoardCREATE「＋ボード追加」確定新しいボードを作成し、ホーム一覧に追加する
DF-02BoardREADホーム画面を開く保存済みボードをすべて一覧表示する
DF-03BoardUPDATEボード名変更を確定ボードのタイトルを更新する
DF-04BoardDELETE「ボードを削除」確定ボードと配下の全リスト・カードを削除する
DF-05ListCREATE「＋リスト追加」確定指定ボードに新しいリスト（列）を追加する
DF-06ListREADカンバンボード画面を開くボードに属するリストと各カードを表示する
DF-07ListUPDATEリスト名変更 / 順序変更（ドラッグ）リストのタイトルまたは並び順を更新する
DF-08ListDELETE「リストを削除」確定リストと配下の全カードを削除する
DF-09CardCREATE「＋カード追加」確定指定リストに新しいカードを作成する
DF-10CardREADカードをクリックカードの詳細情報を詳細モーダルに表示する
DF-11CardUPDATE詳細モーダルで編集 / ドラッグ移動タイトル・説明・期限・優先度・ラベル・チェックリスト・所属リストを更新する
DF-12CardDELETE「カードを削除」確定カードを削除する
DF-13TemplateCREATE「テンプレートとして保存」確定カードの内容（タイトル・説明・優先度・ラベル・チェックリスト）をテンプレートとして保存する
DF-14TemplateREADテンプレート一覧を開く保存済みテンプレートを一覧表示する
DF-15TemplateUPDATEテンプレート編集を確定テンプレートの内容を更新する
DF-16TemplateDELETE「テンプレートを削除」確定テンプレートを削除する
DF-17LabelCREATEラベル作成を確定新しいラベル（名前・色）を作成する
DF-18LabelUPDATEラベル編集を確定ラベルの名前または色を変更する
DF-19LabelDELETE「ラベルを削除」確定ラベルを削除し、付与済みカードからも除去する
