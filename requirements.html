Section 01

プロジェクト概要

本プロジェクトは、チームまたは個人がタスクをカンバン方式で管理できるWebアプリケーション「タスクボード」を開発するものです。ブラウザ上で動作し、インストール不要で利用できるシングルページアプリケーション（SPA）として実装します。

項目内容
プロジェクト名タスクボード Webアプリ
開発形態スクール課題（個人開発）
実装技術HTML / CSS / JavaScript（バニラJS）
動作環境モダンブラウザ（Chrome / Firefox / Safari / Edge）
データ保存ブラウザの localStorage（サーバー不要）
Section 02

目的・背景

タスク管理ツール「Trello」を参考に、カンバンボードの基本操作をHTML/CSS/JavaScriptで再現することで、フロントエンド開発の基礎スキル（DOM操作・イベント処理・状態管理・レスポンシブデザイン）を実践的に習得することを目的とします。

達成したい学習目標

  • HTML/CSSでのUIコンポーネント設計
  • JavaScriptによるDOM操作と状態管理
  • ドラッグ＆ドロップAPI（HTML5）の実装
  • localStorage を使ったデータ永続化
  • レスポンシブデザイン（モバイル対応）
Section 03

機能要件

各機能には優先度を設定します。Must は必須実装、Want は実装予定、Nice は余裕があれば対応します。

3.1 ボード管理

ID機能説明優先度
F-01 列（カラム）表示 「TODO」「進行中」「完了」の3列を固定表示する Must
F-02 カード件数バッジ 各列のヘッダーにカード件数を表示する Must
F-03 列のスクロール カードが多い場合、列を縦スクロールで閲覧できる Must

3.2 カード操作

ID機能説明優先度
F-10 カード追加 「カードを追加」ボタン押下でフォームを表示し、テキスト入力後にカードを作成できる。Enterキーでも追加可能。 Must
F-11 カード削除 カードにホバーすると表示される「×」ボタンでカードを削除できる Must
F-12 カードタイトル編集 カードのテキストをダブルクリックするとインライン編集モードになり、Enterで確定・Escapeでキャンセルできる Must
F-13 ドラッグ＆ドロップ カードを別の列へドラッグして移動できる。ドロップ先は視覚的にハイライトされる。 Must
F-14 期限日の設定 カード作成時に期限日（任意）を設定できる。設定済みカードには日付バッジを表示し、期限切れ・当日・3日以内・それ以降で色分けする。 Want

3.3 データ管理

ID機能説明優先度
F-20 自動保存 カードの追加・削除・移動・編集のたびに localStorage へ自動保存する Must
F-21 初期データ 初回起動時はサンプルカードを表示し、ボードの使い方を伝える Want

3.4 UI・アクセシビリティ

ID機能説明優先度
F-30 ダーク/ライトテーマ ヘッダーのボタンでテーマを切り替えられる（ライト / ダーク / システム連動） Want
F-31 レスポンシブ対応 スマートフォン幅では列を縦並びに切り替える Must
F-32 キーボード操作 フォーム内でEnter確定・Escapeキャンセルが動作する Must
Section 04

非機能要件

カテゴリ要件
パフォーマンスページロード後、3秒以内に操作可能な状態になること
互換性主要モダンブラウザ（Chrome 120+、Firefox 120+、Safari 17+、Edge 120+）で動作すること
可用性オフライン環境でも利用可能であること（サーバー依存なし）
保守性コードはファイル1つにまとめ、クラス名とコメントで構造が把握できること
セキュリティ外部へのデータ送信は行わない。XSS対策としてHTML挿入時はエスケープ処理を行う。
アクセシビリティインタラクティブ要素にフォーカス可視化を実装し、aria-label を付与すること
注記： 本課題はシングルユーザー向け実装のため、マルチユーザー同期・認証機能はスコープ外とします。

Section 06

データ定義

データは localStorage のキー kanban_v1 にJSON形式で保存されます。

データ構造

フィールド型説明必須
todoCard[]TODOカラムのカード配列○
doingCard[]進行中カラムのカード配列○
doneCard[]完了カラムのカード配列○

カードオブジェクト（Card）

フィールド型説明必須
idstring一意ID（タイムスタンプ＋乱数）○
textstringカードのタイトル○
dueDatestring期限日（ISO 8601形式 YYYY-MM-DD）。未設定時は空文字。–

期限日バッジの色分け

状態条件表示色
期限切れ今日より前赤（date-over）
当日今日と同日濃い黄（date-due）、太字
3日以内1〜3日後黄色（date-soon）
余裕あり4日以上後グレー（date-ok）
Section 07

制約・前提条件

サーバー不要
バックエンド・データベースは使用しない。すべての処理をブラウザ上で完結させる。
外部ライブラリ
外部ライブラリは使用しない。バニラHTMLとJavaScriptのみで実装する。
データの永続性
データはブラウザの localStorage に保存されるため、ブラウザのデータ削除で消える。複数デバイス間の同期は対象外。
ファイル構成
HTMLファイル1ファイルで完結させる（CSS・JS はインライン記述）。
対象ユーザー
シングルユーザー前提。マルチユーザー機能・認証・権限管理は対象外。
